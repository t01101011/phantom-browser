# Matrix Research Browser — Roadmap Snapshot

Canonical active roadmap: `PLAN.md`.

The old Phantom Browser implementation is shelved as a historical prototype. Do not continue its feature work unless the direction is explicitly reopened.

Current direction:
- Foundation: MultiZen fork, pending license/runtime audit.
- Benchmark: Donut Browser features only; no Donut/Wayfern branding, hosted service reuse, token reuse, or entitlement bypass.
- Product: Windows-first local Chromium profiles, clean tabs/windows, extensions, per-profile proxy and 2FA workflow, MCP/API.
- Visual: near-black UI with restrained Matrix green accent, low-profile Phantom Research aesthetic.
- Immediate next gate: separate MultiZen workspace, dependency/license matrix, baseline Windows build/smoke.
